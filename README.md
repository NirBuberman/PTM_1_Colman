# PTM_1 – Java OOP Project

פרויקט תרגילים בקורס פת"מ 1 במכללה למינהל, המיושם בשפת **Java** בהתאם לעקרונות תכנות מונחה עצמים (OOP) והמצגות של הקורס.

הפרויקט נבנה בצורה מודולרית ומבוסס על:
- עקרונות **OOA / OOD** (ניתוח ועיצוב מונחה עצמים)  
- עקרונות **GRASP** ו-**SOLID**  
- שימוש ב־**Design Patterns** מתאימים (למשל Singleton, Flyweight)  
- דגש על **High Cohesion** ו־**Low Coupling**

---

## 🎯 מטרת הפרויקט

המטרה היא לתרגל:
- תכנון נכון של מחלקות ואחריות (Responsibility Assignment)
- עבודה עם אובייקטים בלתי־ניתנים לשינוי (Immutable Objects)
- שימוש ב־interfaces וממשקים בין ישויות
- שימוש ב־Singleton לניהול אובייקטים משותפים במערכת
- בניית מנגנון בסיסי של **pub/sub** (פרסום–מנוי) בתור תשתית לגרף חישובי (Computational Graph) בתרגילים הבאים.
